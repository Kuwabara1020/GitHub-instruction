# サッカー試合振り返りサービス

## 概要
子どもが所属するサッカーチームの試合結果や動画・写真を記録し、
子ども自身が試合を振り返るためのサービスです。

## 背景・目的
試合のスコアや映像を残して振り返ることで、
子どもが自分のプレーを見直し、成長につなげられるようにします。

## 対象ユーザー
- サッカーをしている子ども
- 保護者
- チームの指導者

## ユーザーストーリー
- 試合後に、自分のプレーや試合結果を振り返りたい
- 自分ができたこと・できなかったことを記録したい
- 次の試合で意識することを決めたい
- 過去の試合と比較して、自分の成長を確認したい

## 主な機能
- 試合情報の登録（公式試合・練習試合）
- スコアの記録
- 試合動画・写真の登録と閲覧
- 試合の振り返り

## 利用の流れ
1. 試合情報を登録する
2. スコアや動画・写真を記録する
3. 試合を振り返る

## 開発状況
要件を整理中です。

## 今後の予定
- 試合情報の登録機能
- スコア記録機能
- 動画・写真の閲覧機能
- 振り返り機能

## 注意事項
子どもの写真・動画を扱うため、閲覧できる人の範囲やデータの取り扱い方針を検討します。
